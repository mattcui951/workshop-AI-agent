# Prompt 2: C4 diagram and design document

Using the attached PRD and the design we chose, produce:

1. A C4 container diagram as a plain text outline (people, the service, its database, external systems, and what flows on each arrow).
   Containers only. No classes.
2. A one-page design document with these headings: Context, Decisions (each with the alternative you rejected and why),
   Data model, API summary, Risks, Open questions.

Keep it scoped to ONE service. If something belongs to another system, show it as an external box.
