# Prompt 3: find the most important gaps in the PRD

Act as a skeptical senior engineer reading the attached PRD before sprint planning.
Find the FIVE gaps or ambiguities that would cause the most rework if nobody answered them, most important first.
Keep it short. For each one give, in one line each:
- the requirement it relates to
- the question you would ask the product owner
- a reasonable default you would assume if nobody answers

Think about: identifiers, allowed state changes, duplicate and out-of-order messages, who may call what, timestamps,
performance and availability targets, failure handling, and security. Do not write any code.
